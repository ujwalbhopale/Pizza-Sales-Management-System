Pizza Sales SQL Project:
This is a SQL-based data analysis project on pizza sales data. 
It includes four related tables: orders, order_details, pizzas, and pizza_types. 
The project uses SQL queries to answer key business questions and generate insights from the data.

Tables Used:
pizza_types: Contains pizza type ID, name, category, and ingredients
pizzas: Contains pizza ID, type ID, size, and price
orders: Contains order ID, date, and time
order_details: Contains details of pizzas in each order (pizza ID and quantity)

SQL Questions Solved:
1. Calculate the total revenue generated from pizza sales?
2. Join the necessary tables to find the total quantity of each pizza category ordered?
3. Determine the top 3 most ordered pizza types based on revenue?
4. Calculate the percentage contribution of each pizza type to total revenue?
5. Analyse the cumulative revenue generated over time?

Tools Used:
MySQL
SQL

How to Use:
Clone the repository or download the SQL files
Run the CREATE TABLE and INSERT statements in a MySQL environment
Run the SQL queries to explore and analyze the data based on the questions above
